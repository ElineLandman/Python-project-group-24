# Schiphol COVID-19 Passenger Traffic TIL6022
This repository contains a reproducible exploratory analysis of Schiphol passenger traffic from 1992 onward and Dutch COVID-19 case reports.

## Run
1. Create a Python 3.12 environment.
2. `pip install -r requirements.txt`
3. Open `analysis_in_vscode.ipynb` in VS Code/Jupyter.
4. Run all cells in order from the repository root. Figures are saved in `figure/`.

## Files
- `data/`: original supplied Schiphol Excel and OWID CSV
- `Schiphol_COVID19_Project.ipynb`: analysis and research report
- `figures/`: output charts

## Data sources
Schiphol Group traffic statistics; Our World in Data COVID-19 case series.
